## Oversimplifications (claim 11)

- O1 concept 03:89-90, "optimal for a normal shape". The normal-optimal h, (4/3)^(1/5)·s·n^-1/5 = 0.004353, is scipy's 'silverman'. Scott's h is 0.944× that. The textbook rule is about 0.85× for normal data.
- O2 concept 04:18-19, "average of the 126 days before it, itself and the days after it". The 2×m filter gives the two end days half weight. An equal-weight mean differs by up to 9.2e-4 log points.
- O3 concept 04:91-92 and 103-104, "across only eight years". 231 of the 252 positions average 7 values and 21 average 8. The detrended data cover 7.08 periods.
- O4 concept 02:22-24, "the return across the event equals what a holder really earned". This is exact for splits. For a dividend it holds only if P_e = P_{e−1} − D: with D 0.25, P 200→202, the adjusted return is 1.12641% against the holder's 1.12500%.
- O5 concept 02:22 calls the series "back-adjusted", but yfinance's `back_adjust` ("mimic true historical prices", `utils.py:527`) is set to False (`data.py:54`). An interviewer will ask about this; add one sentence.
- O6 00-background §10 item 3 (the M1-edited item), "end='2024-01-01' is needed to include 31 December 2023". 2023-12-31 is a Sunday, and `config.py:79-82` says end='2023-12-31' returns the same data.
- O7 (omission) concept 04:74-78 attributes the "estimate" difference to the trend only. The seasonals differ by up to 0.73%.
- O8 concept 03:106-108 hangs the storm/calm interval claim and ARCH-LM on "excess kurtosis 5.2". ARCH-LM tests clustering, not kurtosis.
