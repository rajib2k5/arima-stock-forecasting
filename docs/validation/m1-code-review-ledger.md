## Defects no claim covers
1. There is no shared payload corpus (envelope_cases.json covers envelopes only), which is why claim 7 failed.
2. payloads.py:83: `math.isfinite(10**400)` raises OverflowError, but the module docstring (:9) says it "never raises".
3. payloads.py:328: `and dates` skips the summary check when `rows == []`.
4. `--check` does not validate the committed envelopes (claim 6 side defect).
5. The manifest `request` is not compared with DOWNLOAD_REQUEST on reuse, and an edited manifest request flows into prices.json.
6. A truncated manifest gives a traceback instead of exit 2.
7. Provenance has no fixed point (claim 12 side defect).
8. The TS integer minimums are untested (OA4).
